Why I built it

A place for
“maybe, later.”

Pinterest is useful for inspiration and discovering products. I wanted a small, private shortlist for the things I’d already found: the original link, why I saved it, and a reason to come back.

Keep an Eye is built around that moment between liking something and deciding to buy it. A save can stay a maybe. A price drop is an invitation to reconsider.

Make it yours

Build your own
Keep an Eye.

The code is public. Your collection lives in your own instance. This is a personal prototype you run yourself.

  1. Start on your computer.

    Install Git and Node.js 24+. Clone the repository, install dependencies, and configure the three private secrets in .env. Then run the app.

  2. Make it available on your phone.

    Deploy to an HTTPS host with persistent storage. Set up the iPhone saving Shortcut using the guide in Settings.

  3. Turn on price alerts.

    Configure web push keys and a daily price-check scheduler. On iPhone, add the app to your Home Screen and enable notifications.

START LOCALLY
git clone https://github.com/meghajainbuilds/keep-an-eye.git
cd keep-an-eye
npm ci
cp .env.example .env
# Set APP_PASSWORD, SESSION_SECRET,
# and CRON_SECRET in .env
npm start

Open http://localhost:3000 after starting.
