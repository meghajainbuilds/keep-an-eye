SAVE FROM ANY WEBSITE

Stay in your shopping flow.

Product page → Share → Save to Keep an Eye. Your link goes straight into your collection. No form, no app switch.

Set this up once on your iPhone using Apple’s Shortcuts app. Keep this guide open while you build it. Your phone may ask permission to connect the first time.

  1. Create the Shortcut. Open Shortcuts, tap +, and name it Save to Keep an Eye. In Details, enable Show in Share Sheet. Accept URLs and Safari web pages.
  2. Get the product link. Add Get URLs from Input, using Shortcut Input. Add Get Item from List and choose First Item from those URLs.
  3. Connect your collection. Create a private saving key below. It can add links, but cannot read or delete your finds.

    Shown only during setup. Keep your Shortcut private. Creating a new key disables the previous one.

  4. Send the link. Add Get Contents of URL and enter this address:
    Show the connection settings

    Method: POST

    Headers: add Authorization, then paste the copied authorization header as its value.

    Request Body: JSON. Add a Text field named url. For its value, choose the Item from List variable from step 2, not typed text.

  5. Show the result. Add Get Dictionary Value for key message in Contents of URL. Add Show Result using that Dictionary Value. Tap Done.
Try it on a product you like.

Open a product page in Safari or Chrome → Share → Save to Keep an Eye. Wait for “Saved to Keep an Eye.” If it is already saved, we’ll tell you. Blocked stores still save as links.

This sets up saving only. Return to your collection to add notes or a price watch. Notification setup is separate.
